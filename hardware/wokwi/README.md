# Simulating the GuideAI cane in Wokwi

[Wokwi](https://wokwi.com) runs the real cane program on a simulated ESP32, wired exactly like
[WIRING.md](../WIRING.md). The parts are laid out top to bottom like the cane's front view
([cane_front_view.png](../cane_front_view.png)):

- **Grip (top):** SOS and MODE buttons with their 10 kΩ pull-downs, and the vibration motor.
- **Box (middle):** the ESP32, buzzer and MPU6050.
- **Bottom of the box:** the laser and the ultrasonic sensor.

All wires run straight. Red is 3.3 V and black is GND; the left-hand red and black lines are the power rails.

| Real part | In the simulator | Same pins |
|---|---|---|
| ESP32 DevKit V1 | ESP32 DevKit V1 | yes |
| RCWL-1601 ultrasonic | HC-SR04, drawn upside down so its pins face the wires | Trig GPIO17, Echo GPIO16 |
| VL53L0X laser | slide potentiometer: 0–100 % = 0–200 cm to the ground | GPIO27 (simulation only; the real laser uses I2C on 21/22) |
| MPU6050 | MPU6050 | SDA GPIO21, SCL GPIO22 |
| Vibration motor + S8050 + diode | purple LED + 220 Ω | GPIO25 |
| Active buzzer + S8050 | buzzer (plays a tone) | GPIO26 |
| SOS / MODE buttons + 10 kΩ | buttons + 10 kΩ pull-downs | GPIO32 / GPIO33 |
| Batteries, TP4056, MT3608, switch | not simulated | check them with the multimeter (WIRING.md section 1) |
| Bluetooth to the app | not simulated: events are printed in the Serial Monitor | test on the real board |

## Open it

1. Go to <https://wokwi.com>, sign in (free), and start a new **ESP32** project (Arduino).
2. In the `sketch.ino` tab, delete everything and paste in
   [../firmware/guideai_cane/guideai_cane.ino](../firmware/guideai_cane/guideai_cane.ino).
   Leave `#define SIMULATION 1` at the top.
3. In the `diagram.json` tab, delete everything and paste in [diagram.json](diagram.json).
4. Press the green **▶ play** button. The Serial Monitor shows `GuideAI cane ready (SIMULATION ...)`
   and `MPU6050: ok`, and the purple "motor" LED blinks once.

Turn your computer's volume down first: the buzzer is loud.

## Tests to run

While the simulation is running, click a part to change what it senses.

| # | Do this | You should see |
|---|---|---|
| 1 | Ultrasonic: set the distance to **300 cm** | `clear`, motor off |
| 2 | Ultrasonic: **120 cm** | `[HAZARD] WARNING: obstacle ahead at chest height`, motor LED pulses |
| 3 | Ultrasonic: **50 cm** | `CRITICAL: stop, obstacle ahead`, motor LED stays on and the buzzer beeps fast |
| 4 | Ultrasonic back to 300. Laser slider at **40 %** (= 80 cm, normal ground) | `clear`, `ground 80 cm (normal 80)` |
| 5 | Laser slider to **25 %** (50 cm: the ground got closer) | `WARNING: step or curb ahead` |
| 6 | Laser slider to **65 %** or more (130 cm: the ground fell away) | `CRITICAL: stop, drop ahead` |
| 7 | Hold **SOS** for 2 seconds | `[EVENT] SOS held 2 s (0x01)` and a long vibration |
| 8 | Click **MODE** | `[EVENT] MODE short press: where am I? (0x02)` |
| 9 | Hold **MODE** for 1 second | `[EVENT] MODE long press: voice commands (0x03)` |
| 10 | Type `v2` in the Serial Monitor and press Enter | `[COMMAND] vibrate pattern 2`, LED blinks twice (the app sends this before a turn) |
| 11 | Type `b10` | `[COMMAND] buzz 1000 ms` |
| 12 | Fall: see below | `[EVENT] fall detected (0x04)` |

**Fall test (MPU6050).** The cane counts as fallen after a hard hit followed by lying still for 2 seconds.

1. Click the MPU6050. Set acceleration **X 0, Y 0.82, Z 0.57**. This is the cane held normally.
2. Set **X 2.0** to make the hit. The monitor prints `[FALL] impact ... watching...`.
3. Within 10 seconds, set **X 0, Y 0, Z 1**. The cane is now lying on the ground.
4. Wait 2 seconds and the fall event appears.
5. Set **Y 1, Z 0** to "pick the cane up" again.

The simulator uses lighter fall settings because you move the sliders by hand: a 1.8 g hit and 10 seconds
to lie still. The real cane needs a 2.5 g hit and only allows 3 seconds.

The laser's "normal ground" slowly adapts to readings within 15 cm of it, like the app does. So if
you leave the slider at a new spot for a while, that becomes the new normal.

## Then the real cane

1. Install the [Arduino IDE](https://www.arduino.cc/en/software).
2. Add the ESP32 boards: **Boards Manager → "esp32" by Espressif**.
3. Add the library **"VL53L0X" by Pololu** (Library Manager).
4. Open `hardware/firmware/guideai_cane/guideai_cane.ino` and change the top line to `#define SIMULATION 0`.
5. Board: **DOIT ESP32 DEVKIT V1**. Turn the cane's power switch **OFF**, plug in the USB cable, and upload.
6. Follow the build order in [WIRING.md](../WIRING.md) section 4, one part at a time. The Serial
   Monitor shows the same messages as the simulator.

The diagram is generated by `make_diagram.py`. Edit the part positions there and run it again, rather than
editing `diagram.json` by hand. It checks that every wire stays straight.
